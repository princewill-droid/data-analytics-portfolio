# Pharmacy Sales Analysis

## Project Overview
This project analyzes pharmacy sales data to understand product performance, revenue, profit, and sales trends.

## Objectives
- Identify the best-selling products
- Calculate total revenue and profit
- Analyze product performance
- Identify areas where sales can be improved
- Create useful insights from pharmacy sales data

## Tools Used
- Microsoft Excel
- SQL
- Power BI
- GitHub

## Key Analysis
The analysis will examine:
- Total sales
- Total revenue
- Total profit
- Quantity sold
- Best-performing products
- Sales trends
